# XLSX-шаблон путевого листа

`waybill.xlsx` — обезличенный шаблон по предоставленному образцу. Данные заполняются общим
`TemplateRendering`: значения передаются готовыми строками, расчётных формул в шаблоне нет.

Организация и подпись руководителя — статический текст шаблона, не поля доменной модели. В дефолтном
шаблоне вместо реквизитов оставлены пустые строки; пользователь может указать их в своём шаблоне.

Плоские плейсхолдеры:

- `{{series?}}`, `{{number}}`, `{{day}}`, `{{month}}`, `{{year}}`, `{{period_start}}`, `{{period_end}}`;
- `{{vehicle_model}}`, `{{vehicle_type}}`, `{{registration_number}}`;
- `{{driver_name}}`, `{{driver_short_name}}`, `{{license_number}}`, `{{license_date}}`, `{{snils}}`;
- `{{odometer_start}}`, `{{odometer_end}}`, `{{distance}}`;
- `{{fuel_type}}`, `{{fuel_refilled}}`, `{{fuel_start}}`, `{{fuel_end}}`, `{{fuel_actual}}`,
  `{{fuel_standard?}}`, `{{fuel_saved?}}`, `{{fuel_excess?}}`.

`{{fuel_type}}` — уникальные марки из отдельных заправок листа через запятую, в порядке первого
появления. Общее сохранённое значение топлива и марка автомобиля по умолчанию в этот список не подставляются.

Вопросительный знак делает плейсхолдер необязательным. Одна строка маршрутной таблицы разворачивается
через группу `routes`: `{{routes.date}}`, `{{routes.odometer_start}}`, `{{routes.odometer_end}}`,
`{{routes.from}}`, `{{routes.to}}`, `{{routes.distance}}`. Каждая строка — один участок; данные группы
и готовность документа проверяет потребитель: движок не проверяет обязательность подполей повтора.

В повторяемой строке поддерживаются горизонтальные объединения. Вертикальные объединения, пересекающие
размножаемую строку, не поддерживаются. Пользовательский текст не интерпретируется как Excel-формула.
