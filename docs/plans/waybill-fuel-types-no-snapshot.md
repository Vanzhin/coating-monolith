# Виды топлива автомобиля без снимка в путевом листе

- Убрать `approvedFuelTypes` из листа и ORM: список поддерживаемого топлива принадлежит автомобилю. Фактический вид топлива в данных листа и будущих операциях не удалять.
- Модель, госномер и другие согласованные реквизиты утверждённого листа по-прежнему фиксируются при утверждении.
- Добавить отдельную миграцию для уже применённой схемы: снять требование снимка из ограничения и удалить колонку, только если в ней нет непустых сохранённых данных. При наличии данных остановиться без их потери; локальную БД без отдельного согласия не менять.
- Проверить текущий список топлива автомобиля, неизменность снимка модели, ORM и отказ миграции при наличии сохранённых данных.
