# Доработка формы карточки водителя

1. Добавить доменный VO СНИЛС с нормализацией, проверкой формата и контрольной суммы по согласованному примеру. Обновить хранение и отображение, проверить граничные случаи и ввод через форму.
2. Добавить «Россия» по умолчанию в объект адреса и для новых адресов в форме, не перезаписывая явно заданную страну.
3. Разделить форму на группы «Водитель», «Маршрут» и «Направления», оформить кнопки добавления и удаления по существующим аналогам, сохранить работу без JavaScript.
4. Использовать удобный ввод даты и числовые поля для целых положительных расстояний, сохранив серверные проверки и проверив их тестами.

Локальные таблицы профилей и путевых листов на момент начала работы пусты; существующие данные и миграции без отдельного согласования не удалять. Старые некорректные СНИЛС потребуют исправления перед загрузкой после введения доменного VO.
