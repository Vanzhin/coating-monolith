# Производственный календарь путевых листов

Статус: реализовано отдельно от заполнителя маршрута.

## Контракт

Доменный справочник `Waybills/Domain/Service/Calendar/ProductionCalendar` хранит исключения 2026 и 2027 годов в статическом PHP-массиве. База данных, миграции и внешний API не нужны.

- `day(DateTimeImmutable $date): CalendarDay` возвращает дату, тип и человекочитаемое название.
- `isDayOff(DateTimeImmutable $date): bool` сообщает, является ли день нерабочим.
- `daysOff(DateTimeImmutable $from, DateTimeImmutable $to): array` возвращает `CalendarDay[]` всех нерабочих дней периода.
- `workingDays(DateTimeImmutable $from, DateTimeImmutable $to): array` возвращает `CalendarDay[]` всех рабочих дней периода.
- `hasDataForYear(int $year): bool` позволяет заполнителю при необходимости показать, что для года используются только обычные выходные.

Обе границы периода включительны. Даты нормализуются до начала календарного дня без использования глобальной часовой зоны и `strtotime()`.

## Правила

- Запись в массиве исключений имеет приоритет над днём недели.
- `holiday`, `transfer_weekend`, `weekend` — нерабочие дни.
- `workday`, `shortened_workday` — рабочие дни, включая рабочую субботу 2027-02-20.
- Без исключения суббота и воскресенье нерабочие, остальные дни рабочие.
- `2027-05-03` — нерабочий понедельник из-за `transfer_weekend`.
- Для года без данных применяется обычное правило: суббота и воскресенье нерабочие, остальные дни рабочие. Это не блокирует чтение календаря или заполнение листа.
