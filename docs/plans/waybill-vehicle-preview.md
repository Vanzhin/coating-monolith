# Превью автомобиля

- На карточке оставить модель, госномер и выделенные пробег и остаток топлива с иконками; меню действий сохранить.
- Адаптировать запрос `GetVehicle` и DTO к текущей модели, без выдумывания даты последних показаний и потери точности топлива.
- По клику открывать серверное превью общим `entity-preview`, как у систем покрытий. Марки топлива, топливо по умолчанию, норма и занятость отображаются в превью.
- Для работы без JavaScript предоставить страницу с теми же подробностями. Проверить авторизацию, отсутствующий автомобиль, карточку, фрагмент и страницу; пересобрать ассеты.
