# Марки топлива путевого листа из заправок

- Убрать общий `fuelType` из формы и из списка принимаемых POST-полей: пользователь выбирает вид топлива только внутри каждой заправки.
- Сохранить внутреннее значение `Fuel.type` для совместимости со старыми записями, сверкой и сериализацией; новый лист использует основную марку автомобиля, существующий сохраняет прежнюю.
- Доменный `RefuelingOperations` возвращает уникальные марки фактических заправок в порядке первого появления. `Waybill` предоставляет этот результат адаптерам.
- Карточка листа и XLSX `fuel_type` используют рассчитанный список через запятую. При отсутствии отдельных заправок список пустой; старые агрегированные заправки не получают выдуманный вид топлива.
- Проверить уникальность и порядок марок, запрет подмены общего `fuelType` через POST, отсутствие select в форме, XLSX-проекцию и полный набор тестов Waybills.
