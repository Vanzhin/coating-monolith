# Калькулятор толщины плёнки: мокрая ↔ сухая с учётом разбавления

Инструмент раздела `/tools`. По устройству — близнец калькулятора смешивания: публичная
страница, SEO-серверный рендер, ростовой хук (подстановка из покрытия для залогиненных).
Оживляет «скоро»-карточку «Толщина мокрой плёнки». Физика (WFT↔DFT с разбавлением) живёт в
ДОМЕНЕ как источник истины и переиспользуется дальше (расход, параметры систем); фронт-
калькулятор дублирует формулу лишь ради офлайна.

## Физика (согласовано с заказчиком)
- Сухой остаток по объёму **VS** (%), свойство покрытия (`volumeSolid`).
- Разбавление **D** — % растворителя, добавленного по объёму к краске.
- Эффективный сухой остаток разбавленной краски: **VS_эфф = VS / (1 + D/100)**.
- Связь толщин: **DFT = WFT × VS_эфф / 100**, отсюда **WFT = DFT × 100 / VS_эфф = DFT × (1 + D/100) × 100 / VS**.
- Считаем в **обе стороны**: ввёл DFT → получил WFT, и наоборот.

## Domain-сервис (источник истины) — СДЕЛАН
Инварианты входов держат VO:
- Новый `Shared/Domain/Aggregate/ValueObject/Percent` — `[0; 100]` (ноль разрешён: разбавление
  0 %). Переиспуём под VS, разбавление, а дальше и `volumeSolid`. Юнит-тест `PercentTest`.
- `Coatings/Domain/Service/FilmThicknessCalculator` (final, stateless):
  - `wetFromDry(Percent $vs, Percent $dilution, PositiveNumber $dryFilm): float`,
    `dryFromWet(Percent $vs, Percent $dilution, PositiveNumber $wetFilm): float`,
    `effectiveSolidsPercent(Percent $vs, Percent $dilution): float` (публичный — для расхода).
  - Толщины — `PositiveNumber` (>0), проценты — `Percent` ([0;100]); единственная явная проверка —
    VS > 0 (делитель, Percent допускает 0). Юнит-тест `FilmThicknessCalculatorTest`.
- Пока без HTTP-эндпоинта (нет server-потребителя; страница считает на клиенте офлайн).
  Готов к вызову из будущих use-case'ов.

## UX (зеркалит смешивание)
- Единый вид «редактируемое (белое) / только-чтение (утопленное) / опорное (акцентная обводка)».
- Поля-параметры (всегда ввод): **Сухой остаток** VS, %; **Разбавление** D, %.
- Пара конвертации: **Сухая плёнка** DFT, мкм; **Мокрая плёнка** WFT, мкм. То из них, куда
  ввели последним — опорное (ring), второе — вычислено. VS/D пустые/0 → результат пуст.
- Единицы подписаны: мкм для толщин, % для VS и D. Ввод фильтруется на месте (цифры + один
  разделитель; запятая → точка, как в смешивании после фикса), `inputmode="decimal"`.
- Ростовой хук: залогинен → тот же coating-search (`app_cabinet_coating_coating_suggest`),
  выбор покрытия подставляет **VS = volumeSolid** (части фиксируются, тег «из покрытия», замок);
  «убрать покрытие» → ручной ввод. Аноним → приманка «Мы, кажется, не знакомы… Войти»
  (ссылка с `_target_path`, как договорились) + ручной ввод VS.
