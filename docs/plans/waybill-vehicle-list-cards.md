# Список автомобилей в общем оформлении

- Заменить таблицу сеткой общих карточек `ecard` в каркасе `components/list_page.html.twig`.
- Показывать модель, госномер, виды топлива, текущие показания и доступные действия; сохранить поиск, пагинацию, CSRF и работу без JavaScript.
- Не добавлять новые стили и специфичные функции покрытий.
- Обновить функциональные тесты списка, проверить Twig и пересобрать ассеты.
- Действия карточки разместить в меню с тремя точками по образцу Coating; статус «Занят» оставить видимым, а при отключённом JavaScript показать запасной список тех же действий.
