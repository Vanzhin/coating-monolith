# Направление и пункт назначения поездки

Исторический план: решение о дробных километрах ниже отменено. Актуальное правило — положительное целое число километров; дальнейшая работа описана в [основном плане](waybill-vehicle-journeys-design.md).

1. Вместо диапазона расстояний использовать одно положительное конечное расстояние; разрешить дробные километры. Направление и поездка используют один неизменяемый объект: адрес, необязательное текстовое название предприятия и расстояние. У поездки дополнительно собственные дата, автомобиль и связь с предыдущей поездкой.
2. В карточке водителя заменить поля «От/До» на «Расстояние, км», добавить предприятие, сохранить серверную валидацию и работу без JavaScript. Обновить отображение и хранение настроек профиля. Данных в БД нет; перенос старого формата не нужен.
3. Адаптировать связанные доменные и инфраструктурные тесты: ввод, ошибки, дробные значения, предприятие, сохранение и общий объект. Пересобрать ассеты.
4. Правила отклонения и сам подборщик отложены: текущий незавершённый подборщик использует устаревший API и диапазоны; не задавать допуск и не утверждать его работоспособность до отдельного согласования.
