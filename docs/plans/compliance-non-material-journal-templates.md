# Контракт плейсхолдеров журналов инструктажа (для .docx)

Эти .docx-шаблоны авторит пользователь в Word и загружает в требование (форма требования → «Шаблон документа»).
Движок заполняет `{{ключ}}`. Повторяющиеся строки **в таблице**: просто поставь `{{log.поле}}` в ячейки строки-образца —
движок сам клонирует эту `<w:tr>` на каждую запись (маркеры `{{log}}…{{/log}}` для таблицы НЕ нужны; они нужны
только для повтора ВНЕ таблицы — списком абзацев). Необязательный ключ — `{{ключ?}}` (пустой, если данных нет).
Подписи (графы «подпись») — на бумаге, система их не заполняет.

## Общие плейсхолдеры (верхний уровень, оба журнала)

- `{{employee_fio}}` — ФИО сотрудника целиком; `{{employee_last_name}}`, `{{employee_first_name}}`, `{{employee_middle_name?}}`
- `{{position_title}}` — должность; `{{department_title}}` — подразделение; `{{org_title}}` — организация
- `{{document_date}}` — дата формирования документа (дд.мм.гггг)
- `{{card_number?}}` — № акта/журнала (из оформления); `{{responsible_fio?}}` — ответственный
- `{{personnel_number?}}`, `{{hired_at?}}`

## Регион строк — `{{log}} … {{/log}}` (одна строка таблицы на запись)

Общие ячейки строки:
- `{{log.issue_date}}` — дата проведения инструктажа
- `{{log.employee_fio}}` — ФИО инструктируемого (сотрудника); `{{log.employee_position}}` — его должность
- `{{log.name}}` — наименование позиции (вид процедуры); `{{log.basis?}}` — основание (из требования); `{{log.model?}}` — примечание

### Журнал противопожарных инструктажей (JournalKind = fire_safety)

Поля инструктажа в строке:
- `{{log.instruction_kind}}` — вид (первичный/повторный/внеплановый/целевой)
- `{{log.instructor_fio}}` — ФИО инструктирующего; `{{log.instructor_doc}}` — № протокола/удостоверения + дата
  (один и тот же инструктирующий для теоретической и практической части — используй эти же ключи в обеих графах)
- `{{log.practice_date?}}` — дата практической части

### Журнал инструктажа на рабочем месте / ОТ (JournalKind = workplace_ot)

Поля инструктажа в строке:
- `{{log.instruction_kind}}` — вид
- `{{log.reason?}}` — причина (для внепланового/целевого)
- `{{log.instructor_fio}}` — ФИО инструктирующего; `{{log.instructor_doc}}` — удостоверение/рег. № + дата
- `{{log.basis?}}` — перечень локальных актов (инструкций) — берётся из «Основания» позиции требования
- `{{log.birth_date?}}` — дата рождения — из карточки сотрудника (необязательное поле профиля; не заполнено → пусто)

## Как подключить

1. Создать требование типа «Процедура», выбрать «Вид журнала» (пожарный / ОТ) и загрузить соответствующий .docx.
2. Оформить акт сотруднику — поля инструктажа (по виду журнала) появятся в форме; заполнить.
3. «Скачать карточку» на акте — журнал заполнится автоматически по контракту выше.

> xlsx тоже поддерживается (движок умеет оба), плейсхолдеры те же — в ячейках листа.
