# Доступность баз пропорции в калькуляторе смешивания

Статус: реализовано; сборка, профильный functional-тест и браузерные сценарии пройдены.
Ветка: `fix/mix-calculator-ratio-base` от `main`.

## Контекст

На `/tools/mix` после выбора покрытия калькулятор подставляет его объёмную и/или массовую пропорцию. Сейчас `applyFromCoating()` показывает переключатель «Объём / Масса» только при наличии обеих пропорций (`hasVolume && hasMass`). Поэтому при единственной заполненной пропорции пользователь не видит её тип.

Новое поведение заменяет правило «переключатель только при обеих базах» из `docs/plans/tools-mixing-calculator-3-coating-search.md`. Статичная подпись вместо переключателя не нужна: UI должен оставаться единообразным.

## Требуемое поведение

- Покрытие не выбрано — переключатель скрыт.
- Выбрано покрытие без пропорции — переключатель скрыт, текущее сообщение и ручной ввод сохраняются.
- Есть только объёмная пропорция — переключатель виден, «Объём» активен и выбран, «Масса» неактивна (`disabled`).
- Есть только массовая пропорция — переключатель виден, «Масса» активна и выбрана, «Объём» неактивен (`disabled`).
- Есть обе пропорции — оба варианта активны; по умолчанию выбран «Объём», переключение загружает соответствующие части.
- После сброса покрытия переключатель скрывается. При следующем выборе доступность вариантов устанавливается заново, без состояния от предыдущего покрытия.

## Реализация — один шаг

В `app/assets/controllers/mix_calculator_controller.js` изменить управление существующим сегментом:

1. Показывать его при наличии хотя бы одной пропорции (`hasVolume || hasMass`).
2. Централизованно синхронизировать видимость и `disabled` обоих radio по фактически доступным базам.
3. Вызывать синхронизацию при выборе покрытия с пропорцией, выборе покрытия без пропорции и сбросе покрытия.
4. Сохранить текущий выбор базы по умолчанию и `loadBase()`: недоступный вариант нельзя выбрать мышью или клавиатурой.

Разметку `_mix_calculator.html.twig`, CSS, расчёт доз, домен, API и хранение не меняем. Новых элементов и статичных подписей не добавляем.
