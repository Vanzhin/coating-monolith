# Редизайн лендинга и экранов входа

## Контекст и цель

Главная (`/`, для неавторизованных) и auth-экраны. По итогам визуального брейншторма (макеты в `.superpowers/brainstorm/.../embedded-swap-v2.html`) фиксируем новый вид. Бизнес-логики не трогаем — только разметка/стили/подача форм.

## Что меняем (итоговый дизайн)

1. **Лого-плитка `1` — ссылка на главную** (`app_homepage`) на всех экранах, где она есть: лендинг + `/login`, `/sign-up`, `/login-link`, `login_link_sent`, `process_login_link`.
2. **Брендинг по центру** — лого, «1helper», подзаголовок центрированы; фичи остаются левым блоком.
3. **Инструменты — вид C**: убрать акцентную карточку-подложку; строка как у остальных фич + стрелка-шеврон у правого края (`margin-left:auto`) + подпись «Инструменты» акцентным цветом + мягкая подсветка строки (`--sunken`) на ховере. Остаётся ссылкой на `app_tools_index`.
4. **Вход/регистрация прямо на лендинге, свап на месте** вместо перехода:
   - Старт: «Начните работу» + кнопки **Войти** (primary) / **Регистрация** (soft) + мини-ссылка «Вход по ссылке без пароля» + install.
   - Клик рендерит нужную форму в той же области (вход / регистрация / по ссылке), «←» возвращает к кнопкам.
   - Механика — **CSS radio + :checked**, без JS. Формы всегда в DOM; без JS всё работает. Переключение — медленный (0.4s) кросс-фейд (CSS transition, панели абсолютом в контейнере фикс-высоты).
   - Формы натуральной высоты (кнопку искусственно не фиксируем).
5. **Поля ввода — без рамки**, светло-серый блок (`--sunken`), на фокусе мягкое акцентное кольцо (`box-shadow 0 0 0 3px var(--accent-subtle)` + `border-color primary`). Правка общая для `.auth-field > input` → единообразно на всех auth-формах.
6. **Кнопки без линий**: `.auth-btn-ghost` (Регистрация) и `.auth-back` (←) — заливка мягким акцентом (`--accent-subtle` + `--bs-primary`), без обводки, усиление тона на ховере. Кнопку «Установить как приложение» (`_install_button.html.twig`, сейчас `btn-outline-secondary`) перевести в тот же soft-стиль.
7. **Десктоп-сплит**: убрать вертикальную черту (`border-left` у `.ls-right`); левую половину центрировать по вертикали (`.ls-left` → `display:flex; flex-direction:column; justify-content:center`). Справа — свап-панель (кнопки/формы), по центру по вертикали. Встроенной формы-«простыни» справа больше нет — всё через свап.
8. **Телефон/планшет**: одна колонка — герой, под ним та же свап-панель. Карточка белая (`--bs-body-bg`), как десктоп.
9. **Title вкладки — убрать двойную черту** (общий баг приложения).

## Развилки — решено

- **Свап форм**: CSS-radio, без JS (прогрессивно по умолчанию). Не Stimulus-fetch.
- **Регистрация на лендинге**: `HomePageAction` строит `RegistrationFormType` и отдаёт `registrationForm` в шаблон (как `RegistrationController`). Login/login_link — чистый Twig + `csrf_token('authenticate')` / `csrf_token('login_link')`.
- **Переиспользование форм**: вынести формы входа-по-ссылке и регистрации в партиалы (у входа партиал уже есть), чтобы лендинг и отдельные страницы делили один источник.
- **autofocus**: в партиалах убрать `autofocus` (на лендинге три формы — конфликт); отдельные страницы живут без него.

## Файлы

**Twig:**
- `home/index.html.twig` — пересборка: герой (лого-ссылка, центр-брендинг, фичи, Инструменты C) + свап-панель (кнопки + 3 формы через radio). `title` → `{{ parent() }} | Главная` оставляем (станет корректным после фикса base).
- `security/_login_form.html.twig` — убрать `autofocus` (используется и на лендинге, и на `/login`).
- `security/_register_form.html.twig` — **новый** партиал (вынести форму из `register.html.twig`).
- `security/_login_link_form.html.twig` — **новый** партиал (вынести форму из `login_link.html.twig`).
- `security/register.html.twig`, `security/login_link.html.twig` — заменить тело формы на `include` партиала; лого-плитку → ссылку.
- `security/login.html.twig`, `login_link_sent.html.twig`, `process_login_link.html.twig` — лого-плитку → ссылку.
- `base.html.twig` — `{% block title %}{{ app_name }}{% endblock %}` (без хвостовой ` | `).
- Дочерние title без своего разделителя — дописать ` | `: `cabinet/index`, `cabinet/profile/index`, `cabinet/profile/settings`, `cabinet/notifications/index`, `cabinet/notifications/settings`, `user/channel/create`, `user/channel/verify`.
- `_shell/_install_button.html.twig` — soft-стиль кнопки.

**PHP:**
- `HomePageAction.php` — создать `RegistrationFormType`, передать `registrationForm` в рендер.

**CSS:** `app/assets/styles/components/auth.css` — все визуальные правки (поля, кнопки, свап-панель + transition, центрирование брендинга, Инструменты C, десктоп-сплит без черты + вертикальный центр, мобильная колонка, лого-mark как ссылка).

## Проверка

- `cd app && yarn dev` — пересобрать ассеты; смотреть лендинг на десктопе/планшете/телефоне (свап, кросс-фейд, формы, поля, кнопки), `/login`, `/sign-up`, `/login-link` (лого-ссылка, поля), заголовки вкладок (одинарная черта) по кабинету/профилю/security.
- Отправка форм без JS (отключить JS) — вход, регистрация, ссылка работают.
- `./run check` (style/phpstan) по PHP-правке `HomePageAction`.
- Прогнать существующие контроллер-тесты home/security, если есть; не ломать `app_sign_up` поток (форма та же, POST туда же).

## Примечание

CSRF-токены встроенных форм на публичной странице — ровно как сейчас у встроенной формы входа на десктопе; новое поведение риск не добавляет, но проверить, что лендинг не кэшируется с устаревшим токеном (SW precache).
