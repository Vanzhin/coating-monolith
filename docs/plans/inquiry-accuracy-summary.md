# Сводка точности извлечения

- Свернуть блок точности при открытии страницы запросов. В заголовке показать общее число одобренных запросов и цветной индикатор по худшему показателю; подробности оставить внутри.
- Получать общее число одобренных из результата запроса, сохранив отдельно число запросов, вошедших в оценку.
- Заменить подпись «Температура у вещества» на «Температура вещества» во всех местах, включая тесты.
- Проверить затронутые тесты и шаблон; пересобрать ассеты после изменения Twig.
