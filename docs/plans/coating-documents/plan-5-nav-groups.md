# План 5 — Группировка меню-шторки (аккордеон)

Самодостаточный план. Часть UX-пачки Certificates вместе с `plan-6-document-list-facets.md`
(список документов) и `plan-7-document-references.md` (референсы). Отдельный деплой — тривиальный,
затрагивает один Twig-регион.

## Цель

В `#mainMenu` (offcanvas-шторка) разбить плоский список навигации на две сворачиваемые группы:
**Покрытия** и **Документы**. Стиль тот же, без новых компонентов и цветов.

## Текущее состояние

- Единственный шаблон меню — `app/src/Shared/Infrastructure/Templates/base.html.twig`,
  зона «навигация» (~строки 486–519): плоский `list-group list-group-flush` из
  `<a class="list-group-item list-group-item-action">`. Ни групп, ни заголовков.
- Пункты: Покрытия, Системы покрытий, Подготовка поверхности — всем; Производители, Химстойкость,
  Документы, Издатели — под `is_granted('ROLE_ADMIN')`.
- JS (~616–623) закрывает шторку по клику на `#mainMenu .list-group-item`.

## Решение

Внутри зоны навигации — два блока Bootstrap `collapse` (независимые, НЕ single-open;
оба развёрнуты по умолчанию, состояние не персистим). Каждая группа:
- **header-кнопка** `<button data-bs-toggle="collapse" data-bs-target="#...">` с иконкой-шевроном.
  НЕ `.list-group-item` — чтобы не подпадать под close-on-click JS и не закрывать шторку при
  сворачивании (как уже сделано для theme-toggle).
- **collapse-контейнер** с прежними `.list-group-item` ссылками (клик по ним по-прежнему закрывает
  шторку — поведение сохраняется).

Состав групп:
- **Покрытия** (`#menuGroupCoatings`): Покрытия, Системы покрытий, Подготовка поверхности,
  `[ROLE_ADMIN]` Производители, Химстойкость. Заголовок группы виден всем.
- **Документы** (`#menuGroupDocuments`): `[ROLE_ADMIN]` Документы, Издатели. Вся группа —
  внутри `is_granted('ROLE_ADMIN')` (не-админ группу не видит вообще).

Роль-гейты сохраняем как есть: админ-пункты внутри «Покрытия» остаются под своим `is_granted`.

## Детали

- Шеврон: `bi-chevron-down`. Поворот при раскрытии — только если решим анимировать; тогда маленькое
  правило в `app/assets/styles/` (в Twig `<style>` нельзя, правило проекта). По умолчанию — статичный
  шеврон без кастомного CSS. Зафиксировать при реализации.
- Существующий close-on-click JS и CSS `#mainMenu .list-group-item` не трогаем.

## Файлы

- `app/src/Shared/Infrastructure/Templates/base.html.twig` — только регион меню.
- (опц.) `app/assets/styles/components/*.css` — лишь если делаем поворот шеврона → тогда `yarn dev`.

## Тесты

Авто нет (Twig). Ручная проверка:
- обе группы, сворачивание/разворачивание;
- роль-гейт: под не-админом группа «Документы» скрыта целиком, в «Покрытия» — только 3 пункта;
- клик по пункту закрывает шторку, клик по заголовку — нет.

## Проверка

- cs-fixer/phpstan не затрагиваются (чистый Twig). Если трогали CSS — `cd app && yarn dev`.
