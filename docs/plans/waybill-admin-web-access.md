# Доступ к веб-разделу «Авто»

- По согласованному исключению ограничить доступ к `/cabinet/waybill` и `/cabinet/waybills` ролью администратора в `security.yaml`, перед общим правилом кабинета.
- Скрыть раздел «Авто» в мобильном меню и десктопной боковой панели для неадминистраторов.
- Проверить доступ админа, отказ по прямым GET и POST, отсутствие раздела в меню и сохранение доступа к остальному кабинету. Это ограничение распространяется только на веб-маршруты.
