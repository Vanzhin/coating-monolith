# Общая форма автомобиля

- Использовать один набор полей для создания и редактирования: модель, госномер, марки топлива, топливо по умолчанию и норма расхода. Начальное состояние вводится только при создании.
- Передавать при редактировании типизированные марки топлива и значение по умолчанию в агрегат; сохранять через командную шину и существующую транзакцию.
- Сохранять введённые значения при ошибке; не изменять начальное состояние, текущие показания или водителя.
- Проверить создание, редактирование без JavaScript, валидацию, уникальность, CSRF и отсутствие частичного сохранения; проверить Twig и пересобрать ассеты.
