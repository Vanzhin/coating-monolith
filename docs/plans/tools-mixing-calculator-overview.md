# Раздел «Инструменты» — обзор арки

Спека-обзор. Само по себе ничего не реализуется этим файлом — арка режется на деплои,
у каждого свой самодостаточный план (см. ссылки ниже). Дизайн-фаза завершена через
визуальный компаньон (макеты `.superpowers/brainstorm/*/content/*.html`, финал `final-design.html`).

## Контекст и цель

Публичный раздел `/tools` с калькуляторами для нанесения. Работает без залогиненного юзера,
но с ограничением функционала. Первый живой инструмент — калькулятор смешивания (считает
рабочую смесь **частями**). Дальше: расход материала, толщина мокрой плёнки, и др.

## Сквозные принципы раздела

- **Публичность.** `/tools` открыт всем; `security.yaml` не трогаем (защищены только
  `/api`, `/cabinet`, `/user`). У залогиненного раздел встроен в оболочку; у гостя —
  та же страница без оболочки (мобильную лого-шапку и `<main>` видит и аноним).
- **Ростовой хук.** Подстановка параметров ИЗ ПОКРЫТИЯ (пропорция/сухой остаток/ДСТ) —
  только авторизованным и только онлайн. Аноним видит приманку «Мы, кажется, не знакомы.
  Войдите, чтобы искать покрытия и подставлять их пропорции автоматически.» [Войти] и
  вводит значения вручную.
- **SEO — первоклассная цель.** Страницы серверные (Twig/MPA), индексируются под запросы
  («посчитать расход краски»). У каждой: осмысленный `<title>`, meta description, один H1,
  описательный текст, человекочитаемый slug, запись в `sitemap.xml`, разрешение в robots.
  Длинный SEO-текст прячем от глаз в раскрывающийся `<details>` «Как рассчитать» (свёрнут для
  человека, но в серверном HTML — индексируется; **не** `display:none`-для-бота). Короткий
  intro виден. Пустые заглушки НЕ делаем индексируемыми страницами.
- **Офлайн.** Инструмент ничего не сохраняет — арифметика в JS (Stimulus). Страницы раздела
  в `PRECACHE` service worker. Ходит на сервер только автоподстановка из покрытия (Деплой 3),
  она online-only и деградирует изящно.
- **Стиль.** Строго дизайн-система приложения. **Без цветных иконок** — монохром `bi-*`, не
  эмодзи. Переиспользуем `.duration-seg`, `.kv-grid/.kvi`, `bg-body-tertiary`, `--sunken`,
  `.btn-soft-*`/`.btn-primary`, лендинг `.land-*`, оболочку `_shell/*`. Новых стилей минимум.

## Навигация / входы

- Залогиненный: пункт «Инструменты» (`bi-calculator`) в САЙДБАРЕ (десктоп) и в ШТОРКЕ «Ещё»
  (`#mainMenu`, мобайл). **НЕ в нижний таб-бар** (остаётся 4 + «Ещё»). Добавляем вручную в
  `_sidebar` и `#mainMenu`, НЕ через `nav_items` (иначе попадёт в таб-бар).
- Аноним: акцентная ссылка «Инструменты — калькуляторы без входа →» в герое лендинга
  (`home/index.html.twig`, блок `.land-hero` — видна и на десктопе, и на мобиле, т.к. герой
  показывается всегда; `.land-cta` на десктопе скрыт).
- Прямой заход по `/tools`.

## Калькулятор смешивания — UX (итог дизайна)

- Без единиц измерения (числа безразмерны — инспектор мешает в любых единицах).
- «C-логика в A-стиле»: колонка «часть» задаёт пропорцию; «кол-во» вводится в ЛЮБУЮ строку
  или в «Итого» (опорное поле обведено акцентом) → остальные пересчитываются. Без
  переключателя режимов. Оформление — мягкие карточки и плитки.
- Состояния покрытия (Деплой 3): покрытие с пропорцией → части ЗАФИКСИРОВАНЫ (плоский текст +
  замок, тег «из покрытия»); покрытие без пропорции → плашка «нет данных о соотношении» +
  ручной ввод; убрать покрытие → тег «вручную», белые поля, «+ добавить компонент».
- «Объём/Масса» — не единица, а выбор какого из двух соотношений покрытия загрузить; только
  если у покрытия есть оба (Деплой 3).

### Деплой 2 — раздел + калькулятор смешивания (ручной)
`docs/plans/tools-mixing-calculator-2.md`. Хаб `/tools` (Смешивание живое, Расход/WFT «скоро»),
страница смешивания (ручной ввод, офлайн, SEO), вход с лендинга, пункт в сайдбаре/шторке.
Ветка `feat/tools-mixing-calculator` (стеком поверх Д1).

### Деплой 3 — поиск по покрытиям в калькуляторе (auth + online)
`docs/plans/tools-mixing-calculator-3-coating-search.md`. Typeahead по покрытиям (репозиторный
`suggest`), подстановка `MixingRatio`, состояния из/без пропорции, auth-гейт + graceful офлайн.
