# Обратное добавление и редактирование цепочки поездок

- «Добавить поездку» при пустом маршруте создаёт строку со страной «Россия». При наличии последней `А → Б` добавляет следующую `Б → А`: назначение равно отправлению последней, расстояние и дата копируются. Отдельной кнопки обратного пути нет.
- В каждой строке показывать вычисляемое «Откуда». Первая отправляется из начальной точки автомобиля, остальные — из назначения предыдущей строки. Предприятие предыдущего назначения тоже участвует в отображении и обратном копировании.
- Stimulus обходит строки в DOM-порядке от начальной точки, обновляет отправления после добавления, удаления и изменения адреса/предприятия. Не отправлять `departure` в POST и не хранить его отдельно в БД.
- В карточке показывать `departure → destination`, используя существующий `RouteLog::departure()`.
- Удаление из середины черновика разрешить: явно удалённый предыдущий узел не считать запрещённым неявным изменением отправления следующей поездки. Между строками показывать «Вставить поездку»: новая строка со страной «Россия», пустым расстоянием и датой предыдущей вставляется в выбранное место. Явно вставленный новый предыдущий узел тоже разрешает перелинковку следующей поездки. Сохранить запрет разрыва при изменении назначения/порядка оставшихся поездок и инвариант различных начальной и конечной точек.
- Передать начальную точку автомобиля в DTO и форму. Сохранение продолжает получать только итоговый список `trips[i]`; серверные row-actions не добавлять.
- Проверить доменную перелинковку, HTTP-сохранение после удаления середины, браузерное добавление `А → Б → А`, обновление отправлений, перенумерацию, одометр, Twig, PHPStan, стиль и полный PHPUnit. Ассеты пересобрать.
