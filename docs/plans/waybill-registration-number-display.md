# Отображение и поиск госномера

- Показывать сохранённый госномер заглавными буквами в списке, форме, показаниях и подсказках поиска; в хранилище оставить нижний регистр. Для XLSX использовать доменный `RegistrationNumber::formatted()`, например `x121ta777` → `X121TA777`.
- Сохранить регистронезависимый поиск и существующее ограничение уникальности нормализованного номера.
- Проверить поиск и отказ при создании дубликатов в разных регистрах, отображение, Twig и ассеты. Восстановление переходных форм редактирования и показаний не входит в этот шаг.
