# Личный список путевых листов

- Показывать в общем списке только листы автомобиля текущего водителя, определяя пользователя по владельцу профиля водителя. Правило одинаково для администратора и остальных пользователей; переданный извне идентификатор владельца не расширяет выборку.
- Черновик следует за текущим водителем автомобиля; после выхода водителя лист скрыт до посадки следующего. Доступ к отдельному листу не менять.
- Оформить список через `components/list_page.html.twig` по образцу покрытий. Кнопка «+» открывает создание для автомобиля текущего водителя; если автомобиля нет, предложить перейти к выбору автомобиля. У одного водителя не более одного автомобиля.
- Поиск автомобиля через существующий `VehicleFilter` / `findByFilter`, без нового метода репозитория. Проверить владельцев и подмену фильтра, администратора, смену водителя, кнопку на обеих ширинах, отсутствие автомобиля, сохранение ограничений создания, Twig и сборку ассетов. Рабочую БД не менять.
